Routines are scenes with a trigger. They remove friction from things you do every day. Use them for convenience, and keep them easy to cancel.

## Morning

- **Trigger:** weekday alarm time, or a voice phrase such as "good morning".
- **Actions:** gentle bedroom light, geyser or kitchen light on, and a spoken weather summary if your assistant supports it.
- **Tip:** make a separate weekend version, or restrict it to weekdays.

## Arriving home

- **Trigger:** the first person arrives, or the front door opens in the evening.
- **Actions:** entry and hall lights on, AC to a set temperature, and a notification to the family.
- **Tip:** use the door sensor as a second trigger, since phone location can be late.

## Leaving home

- **Trigger:** a "leaving" button or the last person leaves.
- **Actions:** all lights and fans off, AC off, indoor cameras on, and a reminder notification to check the door.
- Never include "unlock" or "disarm" actions ([designing automations safely](/learn/designing-automations-safely)).

## Work from home

- **Trigger:** a voice phrase or schedule.
- **Actions:** study lights to cool white at a bright level, do-not-disturb on the speaker, and the AC set to a fixed value.
- **Tip:** add an end-of-day routine that returns lights to warm tones.

## Movie night

- **Trigger:** a voice phrase.
- **Actions:** dim the main lights, switch on bias lighting behind the TV, close curtains if motorised, and set the AC.
- **Tip:** include a "lights back up" phrase.

## Cleaning

- **Trigger:** weekdays at 11:00 when everyone is out.
- **Action:** start the robot vacuum ([robot vacuums](/learn/robot-vacuums)).
- **Tip:** only run when the house is empty and set no-go zones for cables and bowls.

## Build them well

1. Create a **scene** for each state first, then attach triggers.
2. Say the phrase aloud in different ways to see what the assistant understands.
3. Keep each routine under about six actions.
4. Give each routine a **cancel or undo** phrase.
5. Review routines each season.

## Keep family in mind

Share routines with the household so no one is surprised when the lights change. Make sure everyone knows how to use the **physical switches** and the manual controls. Children and guests should never depend on an app to use the house.
